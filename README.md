# Snake: Pixel Rush

Ретро-версия змейки для браузера с элементами прогрессии:

- Комбо-система (чем быстрее ешь, тем выше множитель)
- Случайные события в забеге (гипер-скорость, золотой дождь, зеркальное управление)
- Миссии с наградами
- Постоянные апгрейды за монеты
- Рывок по пробелу с кулдауном

## Запуск локально
Открой `index.html` в браузере.

## GitHub Pages
1. Залей проект в репозиторий.
2. В `Settings → Pages` выбери ветку `main` (или текущую) и папку `/root`.
3. Сохрани — через минуту игра будет доступна по ссылке GitHub Pages.
